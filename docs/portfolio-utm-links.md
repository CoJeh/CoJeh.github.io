# Portfolio UTM link pack

Base URL: `https://cojeh.github.io/`

These links identify the acquisition channel without identifying an individual recipient.

| Placement | Ready-to-use URL |
|---|---|
| LinkedIn profile / Featured section | `https://cojeh.github.io/?utm_source=linkedin&utm_medium=profile&utm_campaign=job_search_portfolio` |
| PDF or Word CV | `https://cojeh.github.io/?utm_source=cv&utm_medium=document&utm_campaign=job_search_portfolio` |
| Recruiter outreach email | `https://cojeh.github.io/?utm_source=recruiter_email&utm_medium=email&utm_campaign=job_search_portfolio` |
| Job application form | `https://cojeh.github.io/?utm_source=job_application&utm_medium=application&utm_campaign=job_search_portfolio` |
| LinkedIn post | `https://cojeh.github.io/?utm_source=linkedin&utm_medium=social_post&utm_campaign=portfolio_content` |
| WeChat article or profile | `https://cojeh.github.io/?utm_source=wechat&utm_medium=social&utm_campaign=portfolio_content` |

## Rules

- Use lowercase channel values with underscores.
- Never add a person’s name, email address, company-specific secret, or application ID.
- Keep the same campaign name long enough to compare channels.
- If a campaign materially changes, create a new general campaign label such as `job_search_portfolio_2026_q4`.
